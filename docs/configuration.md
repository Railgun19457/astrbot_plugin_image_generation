# 配置说明

配置项均在 AstrBot WebUI 中维护，本文列出各配置分组的含义与默认值。

## 基础配置

| 配置名        | 默认值                             | 说明                                                                                                                                            |
| :------------ | :--------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------- |
| 启用 LLM 工具 | 生图工具、预设查询工具、生图任务工具 | 选择允许 LLM 调用的工具。可选项包括生图工具、预设查询工具、生图任务工具和预设编辑工具；预设编辑工具开启后 AI 可创建或删除预设。                 |

## API 供应商配置

每个供应商都包含以下通用配置，部分供应商会额外提供适配器专属配置项。

| 配置名       | 说明                                                          |
| :----------- | :------------------------------------------------------------ |
| 供应商名称   | 供应商显示名，也是模型格式 `供应商名称/模型名称` 的前半部分。 |
| 接口地址     | 供应商接口地址。多数适配器可留默认值或填写中转地址。          |
| 代理地址     | HTTP 代理，例如 `http://127.0.0.1:7890`。                     |
| API 密钥     | API Key 或 Token 列表；多个 Key 会自动轮询和重试。            |
| 可用模型列表 | `/生图模型` 中展示和切换的模型列表。                          |
| 模型能力     | 按实际模型能力勾选文生图、图生图、宽高比、分辨率。            |
| 超时时间覆盖 | 单个供应商的超时时间；填 0 使用“运行控制”中的默认超时。       |
| 重试次数覆盖 | 单个供应商的重试次数；填 0 使用“运行控制”中的默认重试次数。   |

常见专属配置：

- `openai_chat`：可配置提示词前缀、`modalities` 和额外请求体 JSON。
- `openai`：使用 GPT Image 2 系列模型；静态图片支持 1K/1.5K/2K/4K 分辨率与宽高比组合。文生图默认可使用 SSE，不支持流式的兼容站点可关闭该开关。文生图和图生图均可选择 png/jpeg/webp/gif 输出格式，默认 png；GIF 设置与限制见下文。
- `volcengine_ark`：仅适配 Seedream 5.0 Pro / Flash，支持标准 API 与 Agent Plan 切换；Agent Plan 需专属 API Key 和套餐模型（默认列表含 `doubao-seedream-5.0-pro`）。分辨率支持 1K/1.5K/2K，参考图数量不额外限制；Flash 的 `fast` 按 standard 发送。
- `gitee_ai`：可通过图像接口模式自动或手动选择 `generations` / `edits`。
- `siliconflow_adapter`：可配置反向提示词、推理步数和提示词遵循强度。
- `agnes_ai`：可选择国际版（`https://apihub.agnes-ai.com`）或中国版（`https://api.agnes-ai.cn`）接口，也可直接填写接口地址；API Key 按区域区分。2.1/2.5 使用 `size` 档位 + `ratio`，2.0 使用像素 `size`。可选择 `base64` 或 `url` 响应格式，图生图参考图通过 `extra_body.image` 数组发送。
- `codex_responses`：固定发送 `model`、`input` 与 `tools: [{"type":"image_generation","output_format":"png"}]`；填写服务根地址和接口路径（默认 `/codex/responses`，标准 Responses 可填 `/v1/responses`）。无参考图时发送文本 `input`，有参考图时发送多模态 Responses `input`，仅支持同步结果；详见 [Codex Responses 接口配置](codex-responses.md)。
- `modelscope`：调用 API-Inference 异步图像接口，使用 ModelScope Access Token 提交、轮询并下载结果；可配置轮询间隔、总等待时间、反向提示词和尺寸映射。默认模板仅启用文生图；需要模型明确支持后才启用图生图。收到 `task_id` 后不会通过外层重试重新提交任务；详见 [ModelScope 接口配置](modelscope.md)。
- `custom_http`：可配置请求方法、请求头、查询参数、请求体、图片结果路径、结果类型、错误路径和成功状态码；详见 [自定义 HTTP 接口配置](custom-http.md)。
- `comfyui`：上传 ComfyUI API 格式工作流文件并轮询结果；支持提示词自动写入、参考图上传、宽高比/分辨率节点映射和尺寸映射。可用模型列表仅用于显示，实际模型由工作流加载节点决定；详见 [ComfyUI 工作流配置](comfyui.md)。

### OpenAI GIF 动图

在 OpenAI 供应商中将「GPT Image 输出格式」设为 `gif`，并选择支持 GIF 且账号已获预览权限的模型，例如 `gpt-image-2.6-sunburst` 或 `gpt-image-2.6-flare`。旧供应商的可用模型列表不会自动覆盖，需要手动补充模型并切换；仅修改输出格式不会自动切换模型。

| 配置键 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `output_format` | `png` | 选择 `gif` 后生成完整动图；文生图 `/v1/images/generations` 和图生图 `/v1/images/edits` 均生效。 |
| `frame_count` | `9` | 每张动图的帧数，整数 2～16；仅 GIF 输出时发送。 |
| `frame_duration_ms` | `200` | 每帧时长，整数 20～2000 毫秒，接口按 10 毫秒取整；仅 GIF 输出时发送。默认动画约为 1.8 秒。 |
| `gif_size` | `auto` | GIF 每帧尺寸，替代普通宽高比和分辨率设置。可用 `auto` 或 `512x512` 等宽x高，两边均须为正整数且为 16 的倍数。 |

- 在提示词中描述主体、动作和循环方式；有静态参考图时走编辑接口。GIF 参考图仍沿用原有首帧转静态图片的流程，不代表支持逐帧编辑输入动图。
- GIF 自动禁用 SSE，即使「使用 SSE 流式请求」开启也只接收最终完整结果；不发送部分图片、蒙版或自定义输出压缩参数。切回静态格式后恢复原有流式开关和尺寸设置，忽略 GIF 专属参数。
- 帧数、帧尺寸和单次动画数量共同受模型像素预算限制；默认 `auto` 由接口选择尺寸。遇到尺寸/像素预算错误时减小帧数或尺寸，不自动降级为 PNG，也不擅自减少帧数。
- 本地会拒绝越界或非整数的帧参数，以及格式不正确的帧尺寸，不为此重试请求。模型权限和具体像素上限由供应商判断；兼容站点需自行确认支持情况。
- 返回的 Base64 或 URL 结果按原始字节保存为 `.gif`，持久化和投递不转成静态图；接收平台是否播放动画取决于其自身能力。

依据：[OpenAI GIF 输出指南](https://developers.openai.com/api/docs/guides/image-generation#generate-animated-gif-output)、[Images 编辑接口参数](https://developers.openai.com/api/reference/resources/images/methods/edit)。

## 生成与结果配置

| 配置名               | 默认值               | 说明                                                                                            |
| :------------------- | :------------------- | :---------------------------------------------------------------------------------------------- |
| 生图模型             | 自动选择首个可用模型 | 当前使用的模型，可通过 `/生图模型` 或 WebUI 页面右上角的模型选择器更新。                         |
| 默认出图数量         | 1                    | 未在指令末尾或 LLM 工具中指定数量时，单个生图任务默认生成的图片数量。                           |
| 单次最大出图数量     | 10                   | 单个生图任务最多生成的图片数量；用户请求超过该值时会自动截断。                                  |
| 单条消息最多图片数   | 5                    | 多张图片发送给用户时，每条消息最多携带的图片数量；结果信息附加在最后一批。                      |
| 默认图片宽高比       | 不指定               | 可选不指定、1:1、2:3、3:2、3:4、4:3、4:5、5:4、9:16、16:9、21:9；不指定时请求中不携带比例字段。 |
| 默认分辨率           | 不指定               | 可选不指定、1K、1.5K、2K、4K；不指定时请求中不携带分辨率字段，仅部分适配器支持。                |
| 显示结果信息         | 用量                 | 发送图片后可附加耗时、模型、生成数量、用量和任务 ID；用量仅在开启每日额度时显示。               |
| 开始生图任务提示模板 | 已开始生图任务       | 生图开始时发送的提示文本；留空则不发送，默认包含任务 ID。                                       |

开始生图任务提示模板支持这些占位符：`{reference_image_count}`、`{image_count}`、`{count}`、`{prompt}`、`{preset}`、`{presets}`、`{persona}`、`{personas}`、`{aspect_ratio}`、`{resolution}`、`{task_id}`、`{model}`、`{mode}`、`{reference_images_block}`、`{image_count_block}`、`{count_block}`、`{preset_block}`、`{persona_block}`。其中 `{preset}`/`{presets}` 仅表示命中的预设，`{persona}`/`{personas}` 仅表示命中的人设。

当同时使用人设、预设和附加提示词时，插件会将最终提示词整理为轻量分块，例如 `[人物设定]`、`[预设提示词]`、`[附加提示词]`，帮助模型区分不同来源的意图；只有单一来源时会保留原始文本。

| :--------------------- | :----- | :--------------------------------------------------------------------------------------------- |

| 重试次数               | 3      | 单次模型请求失败后的默认重试次数；供应商配置可单独覆盖。                                       |

## 提示词模板配置

预设模板和人设模板在同一个配置组中维护。

| 配置名         | 默认值 | 说明                                                                 |
| :------------- | :----- | :------------------------------------------------------------------- |
| 提示词正文匹配 | 关闭   | 可勾选预设、人设或两者。默认关闭，保持仅从提示词开头连续词匹配。     |
| 预设名称       | 内置   | 用于 `/生图` 开头名称、显式预设参数，以及可选的提示词正文匹配。      |
| 预设提示词     | 内置   | 使用该预设生图时会拼接到提示词中。                                   |
| 预设宽高比     | 不覆盖 | 可选；选中具体值时命中该预设才应用，用户显式指定的宽高比优先。       |
| 预设分辨率     | 不覆盖 | 可选；选中具体值时命中该预设才应用，用户显式指定的分辨率优先。       |
| 预设参考图     |        | 可选；当前模型支持图生图时会自动作为参考图。                         |
| 人设名称       |        | 用于 `/生图` 开头名称、显式人设参数，以及可选的提示词正文匹配。      |
| 人设文本描述   |        | 使用该人设生图时会作为人物设定提示词。                               |
| 人设参考图     |        | 可选；当前模型支持图生图时会自动作为参考图。                         |

预设与人设的参考图都直接上传文件；参考图按「预设 → 人设 → 当前消息或引用图片 → 显式传入的参考图」的顺序合并，并自动去重。模型不支持图生图时参考图会被忽略，不影响任务执行。

出图尺寸优先级为「用户显式参数 → 预设模板 → 默认配置」；同时命中多个预设时，取第一个填写了该字段的预设。

预设模板自带 4 个内置默认预设（手办化、表情包、蜡笔画、GrokBot），可在配置页面直接修改或删除。

旧版 `名称:提示词` 预设仍会被读取（包括 `名称:{"prompt":"提示词","aspect_ratio":"16:9","resolution":"2K"}` 形式），但该 JSON 写法只用于兼容配置里的旧数据，新配置请使用「预设模板」。插件加载配置时会自动把旧版预设迁移到「预设模板」：只复制「预设模板」中还没有的同名条目，同名时以「预设模板」为准，旧版配置项本身不再写入内容（仅保留升级前的旧数据以便回滚）。

`/预设 添加`、`/预设 删除` 和 `edit_image_presets` 工具都会写入「预设模板」，内容按普通提示词处理：宽高比、分辨率和参考图请在配置页面（或 `edit_image_presets` 的对应参数）中设置。保存时会把当前全部预设写入「预设模板」，旧配置项本身不再被改写；删除预设时会同步移除旧配置中的同名条目，避免删除后又被自动迁移或旧配置恢复。

`/预设` 会同时展示预设和人设。预设与人设同名时优先使用预设。默认情况下 `/生图` 只从开头连续词匹配名称。开启“提示词正文匹配”后，`/生图`、LLM 生图工具和公共 API 会在提示词正文中扫描已勾选类型的名称：较长名称优先，每个名称最多应用一次，命中后从附加提示词中移除该名称。英文名称按单词边界匹配，避免 `cat` 命中 `category`；中文名称按子串匹配。末尾单独数字仍会被解析为生成数量，不参与预设/人设和提示词内容。

## LLM 工具

| 工具名                | 配置项名称   | 说明                                                                  |
| :-------------------- | :----------- | :-------------------------------------------------------------------- |
| `generate_image`      | 生图工具     | 根据提示词、预设、人设、参考图、头像引用和生成数量提交生图任务。      |
| `query_image_presets` | 预设查询工具 | 查询预设或人设列表，也可查看指定预设/人设详情。                       |
| `manage_image_tasks`  | 生图任务工具 | 查看当前会话任务列表、查看任务详情、取消仍在进行的任务。              |
| `edit_image_presets`  | 预设编辑工具 | 创建或删除预设（含宽高比、分辨率和参考图 URL）；默认不启用，开启后 AI 可修改预设配置，但不会编辑人设。 |

LLM 生图工具支持 `preset`、`persona`、`aspect_ratio`、`resolution`、`image_count`、`avatar_references`、`reference_images` 和 `use_context_images` 参数。`avatar_references` 可填写 `self`、`sender` 或用户 ID；`reference_images` 支持网络图片 URL，本地路径仅允许当前会话 workspace、AstrBot temp 目录和本插件数据目录。命中的预设或人设会自动带入各自配置的参考图。仅在 LLM 改图显式传入 `use_context_images=true` 时，插件才会按需取得参考图，纯文生图不会自动取图。优先级为当前消息或引用消息中的图片、同一发送者最近缓存的图片、近期历史中最后一条带图的用户消息。缓存按会话和发送者隔离，只保存该发送者直接发送的图片，因此群聊中不会取到其他成员的图片，引用旧图也不会覆盖缓存。未找到可用图片时会取消任务，不会降级为纯文生图。
